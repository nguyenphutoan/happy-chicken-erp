# 🍔 Happy Chicken - Smart Fast-Food Management System

An advanced, full-stack restaurant management system integrating E-commerce, a Point of Sale (POS) system, and AI-driven inventory forecasting. 

## ✨ Key Features

### 👤 Customer Portal (E-commerce)
* **Loyalty Program:** Earn and redeem membership points seamlessly.
* **Secure Payment:** Integrated with VNPAY sandbox for reliable online transactions.

### 👨‍🍳 Staff Portal (POS System)
* **Quick POS:** Efficient order processing for Dine-in and Takeaway.
* **Customer Lookup:** Search customers by phone/email to apply accumulated points and discounts.

### 👔 Manager Dashboard (ERP & AI)
* **AI Inventory Forecasting:** Python microservice using XGBoost to predict daily sales and suggest optimal restock quantities.
* **Product & Stock Management:** Full CRUD operations with image uploads and real-time stock logs.
* **Promotion Engine:** Create complex discount rules (by percentage/fixed amount, specific days, required products,...).
* **HR Management:** Manage staff accounts, track employment status, and securely reset passwords.

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router, Axios, Bootstrap
* **Backend:** Laravel (PHP), RESTful APIs, MySQL
* **AI/ML Service:** Python, FastAPI, XGBoost, Pandas
* **Payment Gateway:** VNPAY Sandbox
